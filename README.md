# 数字华容道

经典滑动拼图。支持 **3×3 / 4×4 / 5×5** 三种难度。

## 在线游玩

**[点击开始游戏 →](https://weexile1.github.io/szhrd/)**

打开链接即可玩，无需安装、无需下载代码。

---

## 玩法

棋盘为 `n × n`，含 `n² − 1` 个数字方块与 1 个空缺。

- 通过空缺上下左右滑动方块
- 将数字排成从上到下、从左到右的 `1 → 最大数`（空缺在右下角）即通关

| 模式 | 规模 |
|------|------|
| 入门 | 3×3 |
| 进阶 | 4×4 |
| 挑战 | 5×5 |

**操作：** 方向键 / WASD，或点击与空缺相邻的方块（手机可点选）。
